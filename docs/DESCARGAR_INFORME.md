# Cómo descargar el informe desde la web (GitHub)

## Opción A — Archivo Markdown (.md)

1. **Vista en el navegador (formateado):**  
   [Abrir informe en GitHub](https://github.com/SergioLSantosR/Compiladores/blob/main/docs/INFORME_COMPILADORES.md)

2. **Descarga directa del texto (Raw):**  
   Clic derecho en la página siguiente → “Guardar como…”  
   [Enlace raw — INFORME_COMPILADORES.md](https://raw.githubusercontent.com/SergioLSantosR/Compiladores/main/docs/INFORME_COMPILADORES.md)

## Opción B — Página web (.html)

Misma información en HTML (mejor para imprimir o guardar como PDF desde el navegador):

- **Vista en GitHub:**  
  [INFORME_COMPILADORES.html](https://github.com/SergioLSantosR/Compiladores/blob/main/docs/INFORME_COMPILADORES.html)

- **Descarga raw del HTML:**  
  [Enlace raw — INFORME_COMPILADORES.html](https://raw.githubusercontent.com/SergioLSantosR/Compiladores/main/docs/INFORME_COMPILADORES.html)

Abre el `.html` descargado con Chrome/Edge → **Ctrl+P** → “Guardar como PDF”.

## Opción C — Clonar el repositorio

```bash
git clone https://github.com/SergioLSantosR/Compiladores.git
```

Los archivos quedan en `Compiladores/docs/`.
